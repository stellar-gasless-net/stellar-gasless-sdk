# Contributing to Stellar Gasless SDK

Thank you for helping build **`@stellar-gasless/sdk`**!

## 🛠️ Local Development Setup

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Build Library**:
   ```bash
   npm run build
   ```

---

## 📌 Pull Request Guidelines

- Ensure `npm run build` succeeds cleanly.
- Keep commits formatted with conventional commit prefixes (`feat: ...`, `fix: ...`, `docs: ...`).
